# 困惑 → 教学选择

| 困惑 | 诊断 | 观察和讲解 | 检验 |
|---|---|---|---|
| 名称太多 | 能指出却叫不出，还是位置也不清？ | 每轮少量结构，名称对应形态与整体位置 | 去标签后换角度命名并说依据 |
| 左右/前后混 | 使用屏幕方向还是人体方向？ | 明确源模型姿态，相机绕行而人体方位不变 | 从背面或侧面判断；不镜像翻图 |
| 形态相似 | 学生依据什么区分？ | 同比例同角度对比一个关键鉴别点，再补必要例外 | 去标签、换顺序，解释判断 |
| 空间关系 | 是遮挡、位置还是参照物缺失？ | 整体聚焦、逐层减少遮挡，保留一个可靠参照 | 回原位说前后/上下/相邻关系 |
| 孔/管/裂/窝 | 单结构与组合空间是否混淆？ | 单骨与相邻骨切换，课件图对应；缺局部网格不假装高亮 | 区分组成、位置、通行物，限课堂范围 |
| 走行分支 | 连续路径还是名称次序混乱？ | 起点—经过—分支—终点分段，缺模型用标明的示意 | 去提示补路径；示意线不是实际走行 |
| 为什么 | 结构事实与功能关联分开看 | 指出可见形态和功能，避免无依据目的论 | 用结构解释现象，不强行扩展临床 |
| 数量/分类 | 计数口径还是典型/特殊混？ | 代表性模型与短表，区分年龄、融合及变异 | 新例子分类，说明适用条件 |
| 看懂却复述不了 | 是否依赖标签提示？ | 去标签口述，只在需要时给一个线索 | 延迟几个问题后换角度再问 |

## 系统范围

运动系统看骨标志、原位关系、关节构成与肌起止；内脏看位置、毗邻、分部与管道；脉管看主干、分支、伴行与汇流；神经看分部、位置、通路与支配；感觉器官看腔、壁、层次与通道；内分泌、生殖看位置、毗邻与模型来源。这是教学范围，不能据此宣称 atlas 全覆盖。

上传课件时提取小学习单元：来源页、学习目标、要辨认结构、难点、所需视角、能执行的观察动作、短检验题。文字疑误对 PDF 图/教材核对。先解决当前问题，不一次生成整章标签和考题。

“颅骨太乱”可先显示少量组成骨，理解共同形成的一个腔/窝；“血管混”先分清流向、分布还是名称；“肌肉怎么动”先看起止与跨关节，再核对简化运动图；“模型与课件不一样”检查观察方向、切开状态、来源、年龄和绘图简化。

用户要求保存时记录日期、主题、出处、学生原回答、具体混淆、纠正依据、复测结果与未解决点。未作答写未测；选择正确不自动记熟练。保存到用户指定位置或当前 outputs，不能写全局 memories。
