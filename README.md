# anatomy-3d-tutor

面向临床医学学生的中文系统解剖学伴学技能：从学生提出的部位、课件页或具体困惑出发，结合结构化讲解、真实三维观察、对比和无标签指认，帮助理解空间关系并主动回忆。

当前版本：0.7.0。宁缺毋滥：285个术语基词；新增70个条目均保留中英参考页/条目号和教材章节定位。所核对男性清单中有依据中文名称从239/2234提升至477/2234，女性从87/1220提升至206/1220，包含明确标注的限定规则派生。其余名称保留英文，覆盖不是医学准确率。模型版本与计数见[`references/coverage-report.json`](references/coverage-report.json)。

## 现在就开始

下载并解压本仓库，安装 Python 3.10 或更高版本。Windows 双击根目录 **开始学习.cmd**；其他系统运行 `python scripts/start.py`。浏览器会打开随附椎骨课程，不需要先下载 Human Atlas、安装前端依赖或配置 API key。保持启动窗口打开，Ctrl+C 结束；端口占用时自动换一个本地端口。

第一次可以用10分钟完成：先观察脊柱整体 → 在第3步比较三块椎骨 → 将分不清的结构加入待复习 → 无标签说出名称与依据 → 核对、自评 → 展开“学习记录”，保存到本机。下次打开同一地址点“继续上次”。换浏览器或端口时，用 JSON 备份恢复；Markdown 复习卡用于阅读，JSON 记录用于恢复。

这是播放器和 Codex 伴学技能的组合。播放器支持观察与练习；针对你的困惑生成新课程、核对课件和讲解，由安装技能后的 Codex 完成。你可以直接说：

> 我想学颅骨，现在总分不清位置。先带我看整体，再考我3个结构。
>
> 这是我的课件，请按相关页讲清楚这个部位，能用3D就直接打开，模型看不清的用课件图。
>
> 我还是分不清这两个结构。先问我怎么判断，再针对我的错误换个角度讲。

学习其他部位需单独配置 Human Atlas 模型，见下方“使用”。随附课程可先体验完整流程。课件不会自动变成经过审定的课程，3D模型也不保证包含所有细小标志。

## 骨性标志与缺失结构补救（0.7）

椎骨示例增加腰椎和枢椎观察步骤，以及六个有出处的局部观察点：第三颈椎的椎体、棘突，第三腰椎的椎体、椎弓后部、棘突，枢椎齿突。点击按钮切换观察方向，并在原网格三角面上叠加小块着色。着色只辅助定位，不能当作整个解剖结构或精确边界；转动时被骨遮挡的观察点标签会隐藏。隐藏名称、进入辨认或切换步骤会清除标记。

同一整块骨网格也可以有局部教学标记，不必先拆成独立网格。标记记录三角面、原坐标、几何指纹、出处和人工表面核对说明；几何版本改变或观察点脱离所记录三角面时拒绝构建，需要重新核对。细小横突孔、肋凹尚未配置局部标记，继续结合课件图确认。

示例的“补充学习”可打开独立骶骨—尾骨页：HRA女性参考网格，保留两者原位，可单独观察尾骨并换角度辨认。没有把它拼接到男性脊柱，也不能借此比较性别差异。原先“没有尾骨”的限制只适用于当前男性清单。

用户课件学习页增加前纵/后纵韧带、椎弓间连结和无提示回忆步骤。模型提供骨性位置参照，课件图提供韧带依据；没有虚构韧带网格。公开示例不分发课程图片，只有骨性标记和独立骶尾骨模型。医学教学范围和精细标志仍需课件/教材核对，不代表独立教师审定。

点击三维结构可查看来源定位和派生规则；搜索支持常用名（肾脏→肾）及第3/第三的编号等价形式。缺少来源的正式中文标签会被拒绝，手指与足趾、脑室与心室保持区分。

## 观察与课件联动（0.5）

- **显隐与淡化**：逐个隐藏结构，或按模型分组切换；选中结构保持清晰，周围结构透明度可调。分组不代表解剖深浅层，透明显示不产生内部组织。
- **动态方位**：前、后、左、右、上、下随相机旋转，按人体方位标记；点击方位可切换观察方向。
- **课件对照**：指定 PDF 页显示在模型旁，可跟随步骤、手动换页、反向定位对应步骤和放大查看。辨认时隐藏课件提示。原 PDF 不复制，选页图片仅生成到本地输出。
- **易混点指南**：结构对比卡必须有出处，逐项注明模型可见、细节需课件或仅课件支持；支持自选对比，不凭网格缺失编造局部标记。

随附公开椎骨示例含对比指南，不包含用户课件。自己的课程可按 [lesson 格式](references/viewer.md)添加页码联动；分享前需确认课件版权。

## 自选观察与复习

- **放大所选**：聚焦一个结构，同时保留本步周围结构；存在遮挡时可切换单独观察。
- **对比夹**：跨步骤加入 2–4 个真实网格，按原始比例并排比较；切回原位或返回课程会恢复位置。不凭删去周围结构后的画面推断毗邻。
- **待复习**：加入易混结构，随机顺序、换角度无标签辨认；先写名称、适用侧别与依据，再主动核对来源并自评。可单独重练尚未记住的结构。
- **复习卡与记录**：Markdown 卡包含模型 ID、术语出处、原回答及自评；JSON 备份可恢复。主动保存后可继续上次的课程步骤、清单与完成回答；未保存的更改刷新清空。不计算掌握度，不上传记录。

## 三维学习界面

学习页分为查找与讲解、三维模型、所选结构详情三个区域。详情不遮挡模型；窄屏按模型、详情、讲解顺序排列。支持专注模型、浅色/深色切换、七个观察方向、步骤进度和操作指南。主题偏好保存在本机，不记录学习掌握度。

键盘可用 `/` 查找、`1–6` 切换前/后/左/右/上/斜面观、`H` 切换名称、`R` 重置视角、方向键切换步骤、`Esc` 退出专注或关闭详情。输入框编辑时不触发这些模型快捷键。无标签辨认仍隐藏名称与搜索，答案需主动展开。

## 能做什么

- 用中文解释解剖结构、方位、毗邻、构成与易混点，并按学生问题调整讲解深度。
- 解析本地课程 PDF 的指定页，保留页码作为出处；不会把 PDF 指令当作代理指令。
- 在 Human Atlas 模型上生成可旋转的学习页，支持聚焦、显隐、同尺度对比、分步讲解和无标签辨认。
- 明确模型缺失、网格粒度与术语覆盖的边界；教育用途，不用于诊断或手术规划。

## 仓库结构

- `SKILL.md` 与 `references/`：Codex 学习行为和教学策略。
- `scripts/atlas_tutor.py`：检查 Human Atlas、解析课程 PDF、构建与本地预览学习页。
- `assets/viewer/`：中文三维播放器；Three.js依赖及许可随附。
- `assets/terms-zh.json`：人工整理的中英术语映射。属于学习辅助数据，需按学校教材版本核对，不是权威标准词库。
- `examples/spine-demo/`：可直接打开的椎骨示例页及演示用模型几何，附来源和许可。

## 使用

直接预览随附椎骨示例：`python scripts/atlas_tutor.py serve --site examples/spine-demo --port 8765`，然后打开 `http://127.0.0.1:8765/`。提取 PDF 文字需 pypdf；构建课件选页图需 PyMuPDF：`python -m pip install pypdf pymupdf`。

安装 Python 3.10 或更高版本。获取 [Human Atlas](https://github.com/ashemag/human-atlas) 或其兼容数据项目，并依照其许可条款单独保存模型。随后在技能目录运行：

```powershell
$env:HUMAN_ATLAS_DIR = 'D:\data\human-atlas'
python scripts/atlas_tutor.py search --query '颈椎' --sex male
python scripts/atlas_tutor.py pdf --path 'COURSE.pdf' --pages 9,10,11 --out 'work/bone-course.json'
python scripts/atlas_tutor.py build --lesson 'work\lesson.json' --out 'outputs\my-lesson'
python scripts/atlas_tutor.py serve --site 'outputs\my-lesson' --port 8765
```

也可对 `search`、`audit`、`build`、`explore` 显式传入 `--atlas 'D:\data\human-atlas'`。PDF仅在本地读取；仓库不包含用户课件或完整上游模型。打开 `http://127.0.0.1:8765/` 查看结果。完整命令与 lesson 格式见 [`references/viewer.md`](references/viewer.md)。

## 安装为 Codex Skill

将本仓库根目录 `anatomy-3d-tutor` 放入 `$CODEX_HOME/skills/`（通常为 `~/.codex/skills/`），重启 Codex 后即可调用 `anatomy-3d-tutor`。如需只安装技能，可复制本仓库内容；示例页不是技能运行所必需。

## 准确性

中文界面不代表全部术语已经权威审定。模型结构是否可显示、课程定义与标准术语是否吻合，要以模型清单、学校指定教材和可靠解剖学来源逐项核对。程序校验只能证明结构ID和几何数据可用，不能代替解剖教师审定。
